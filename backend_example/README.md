# Интеграция авторизации через Telegram в FreeBirdVPN

Этот документ описывает процесс интеграции авторизации через Telegram в приложение FreeBirdVPN.

## Обзор системы

Система состоит из двух основных компонентов:

1. **Frontend (Next.js)** - Telegram Mini App, которое взаимодействует с Telegram WebApp API и отображает интерфейс пользователя.
2. **Backend (FastAPI)** - API сервер, который обрабатывает запросы на авторизацию и управляет данными пользователей.

## Процесс авторизации через Telegram

1. Пользователь открывает приложение через Telegram.
2. Приложение автоматически получает данные пользователя из Telegram WebApp.
3. Данные пользователя отправляются на бэкенд для регистрации/авторизации.
4. Бэкенд генерирует и возвращает токены доступа (access_token и refresh_token).
5. Токены сохраняются в localStorage браузера для последующих запросов.

## Настройка Frontend

В проекте используется хук `useTelegramUser` для взаимодействия с Telegram WebApp API и автоматической регистрации пользователей:

```typescript
// hooks/use-telegram.ts
export function useTelegramUser() {
  // Получение данных пользователя из Telegram WebApp
  // Автоматическая регистрация на бэкенде
  // Управление токенами авторизации
}
```

## Настройка Backend

Бэкенд реализован с использованием FastAPI и предоставляет следующие эндпоинты:

- `/auth/telegram/register` - Регистрация пользователя через Telegram
- `/auth/refresh` - Обновление токена доступа
- `/subscription/info` - Получение информации о подписке пользователя

## Запуск проекта

### Frontend

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev
```

### Backend

```bash
# Установка зависимостей
pip install fastapi uvicorn pyjwt python-dotenv

# Запуск сервера
python backend_example/main.py
```

## Переменные окружения

Создайте файл `.env.local` в корне проекта со следующими переменными:

```
NEXT_PUBLIC_API_URL=http://localhost:8000
```

Для бэкенда создайте файл `.env` в директории `backend_example`:

```
JWT_SECRET_KEY=your-secret-key-here
```

## Безопасность

- В продакшене всегда используйте HTTPS
- Храните секретные ключи в переменных окружения
- Настройте CORS для разрешения запросов только с доверенных доменов
- Используйте короткий срок жизни для access_token и механизм обновления через refresh_token
